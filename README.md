# Guaraní Para Todos

## Objetivo
Desarrollar un prototipo de aplicación móvil para el aprendizaje del idioma guaraní, 
mediante la implementación de contenidos educativos interactivos y herramientas tecnológicas que faciliten su aprendizaje,
mediante pruebas a los usuarios del funcionamiento del mismo.

## Entorno de Programación
- Lenguaje: Java
- IDE: Android Studio
- JDK: javac 25.0.1
- Base de datos: MySQL
- Plataforma: Android Studio
