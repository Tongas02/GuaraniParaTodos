# Arquitectura del sistema

La aplicación “Guaraní Para Todos” utilizará una arquitectura en capas.

- Capa de presentación: interfaces desarrolladas en Android Studio.
- Capa lógica: contiene las funciones y validaciones del sistema.
- Capa de datos: gestiona la información almacenada en MySQL.

La aplicación se comunicará con la base de datos mediante los componentes definidos para cada módulo del sistema.
